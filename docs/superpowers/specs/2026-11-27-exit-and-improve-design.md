# Exit ボタンと改善要望の入口

## 目的

- Your turn に溜まったセッションを、cmux のタブを探しに行かずにダッシュボードから終わらせたい。
- Claude の振る舞いで気になったことを、その場で「xxx にしたい」と書くだけで、直す作業を別セッションに任せたい。

## ゴール / 非ゴール / アンチゴール

- ゴール
  - Your turn の行から、確認を 1 回挟んでセッションを終了し、タブも閉じられる。
  - ヘッダーとセッションの行から改善要望を送ると、新しい cmux ワークスペースで Claude Code が立ち上がり、要望に取りかかる。
- 非ゴール
  - 「完了」の自動判定（PR のマージなど）はしない。終了するかどうかは人が決める。
  - 改善要望の履歴管理や、立ち上がったセッションの進捗追跡はしない（立ち上がれば Live に普通に出る）。
- アンチゴール
  - 確認待ちのセッションに文字を打ち込み、許可ダイアログの選択肢を選んでしまうこと。
  - 要望の本文がシェルのコマンドとして解釈されること。

## 検討した作り方

- A. ヘッダーに入口を 1 つだけ置き、`~/.claude` で立ち上げる。
  - シンプルだが、どのセッションの振る舞いが問題だったかを Claude が見に行けない。
- B. A に加え、各セッションの行にも入口を置き、そのセッションの cwd と会話ログのパスを渡す。（採用）
  - 改善要望はたいてい特定のセッションを見て思いつくので、実際のやり取りを読ませられるのが大きい。
- C. 送る前に直す先をドロップダウンで選ぶ。
  - 対象が様々なので、毎回選ぶ手間が見合わない。

ユーザーは B を選んだ。

## 決まったこと

### Exit

- 対象は Your turn レーンの行（`ask` と `reply`）。完了判定はしない。
- 行に「Exit」ボタンを置き、押すと確認を出す。
- `ask`（Needs you）のときはボタンを無効にする。理由はメモと同じ。
- サーバーは `POST /api/exit` を受け、メモと同じバッファ経由で `/exit` を送ったあと、`cmux close-surface` でタブを閉じる。
- 終了したセッションは `claude --resume` で戻せるので、確認は 1 回で足りる。

### 改善要望

- 入口は 2 つ。
  - ヘッダーのボタン。立ち上げ先は `~/.claude`。
  - 各セッションの行（展開したときの操作の並び）。立ち上げ先はそのセッションの cwd。依頼文に cwd と会話ログ（jsonl）のパスを添える。
- 依頼文は「Claude Code の振る舞いについての改善要望」という定型の前置きと、ユーザーの本文からなる。前置きでは、CLAUDE.md・スキル・フック・settings・メモリ・リポジトリ側の設定のどこを直すべきかを判断してから直すよう求める。
- サーバーは `POST /api/improve` を受け、`cmux new-workspace --cwd <dir> --command <固定のコマンド>` で立ち上げる。
- 要望の本文はコマンド文字列に入れない。サーバーが本文を `~/.cache/cc-dashboard/improve/<ランダム名>.md` に書き、コマンドは `claude "$(cat '<そのパス>')"` だけにする。パスはサーバーが作るので、ユーザー入力がシェルに渡ることはない。
  - 前の会話で「起動後にバッファで貼り付ける」と書いたが、起動完了を待つ処理が要らないこちらに変えた（私の判断）。
- 行から送る場合、サーバーは sessionId から cwd とログのパスを自分で引く。ブラウザから渡されたパスは使わない。

### セキュリティ

- `/api/exit` と `/api/improve` には、既存の `/api/focus`・`/api/memo` と同じ検査（同一オリジン、`X-CC-Dashboard: 1`、JSON のみ）をかける。
- HACKING.md の「Chan to Yare が書き込むのは 2 通りだけ」という記述と Security 節を、終了とセッション起動を加えた内容に更新する。

## 実装する人に任せること

- ボタンとフォームの見た目と置き場所の細部。既存の composer やジャンプボタンの作りに合わせる。
- 依頼文の前置きの正確な文面。
- 一時ファイルを消すタイミング（起動から一定時間後、など）。
- `/exit` を送ってから `close-surface` するまでの待ち時間。
